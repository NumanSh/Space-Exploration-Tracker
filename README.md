# Space Exploration and Astronomy Event Tracker

A C++ application for tracking real-time space events, analyzing orbits, and visualizing astronomical data.

## Features
- **Real-time Data**: Fetches asteroid, launch, and weather data from NASA and other APIs.
- **Interactive UI**: ImGui-based dashboard for filtering and analysis.
- **Personalization**: Visibility predictions based on user location.
- **Simulation**: "What-if" scenarios for orbital mechanics.

## Tech Stack
- **Language**: C++ 20ish
- **Build System**: CMake
- **Libraries**:
  - `httplib` (Networking)
  - `nlohmann/json` (Data Parsing)
  - `Dear ImGui` + `ImPlot` (User Interface)
